## 1. 技术约束

- **Go 自绘，无 webview、无前端构建**（`github.com/egoist/mygo` v0.7.4）；
- 窗口 `TitleBarHiddenInset`，标题条自绘 42px，可拖动，避开窗口控件；
- 页面状态集中在 `uiState`（主线程读），后台工作通过 `Window.Update` 回投；
- 无窗口测试用 `ui.NewTester`（`view_test.go`）；
- 发布构建带 `-tags mygo_noinspector`，开发构建自动带原生 UI 检查器。

## 2. 信息架构

窗口自上而下：**自绘标题栏** → 内容区（侧栏 + 页头 + 页面）→ **状态页脚**。

- **标题栏**只放品牌与版本：它是拖动窗口的把手，状态数字放在这里会跟着鼠标动。
- **页脚**（28 DIP）承载一切「报告型」信息：
  左起 **运行中 · 服务地址 · 数据目录**，右侧 **在途 / 运行时长 / 存储模式 / 适配器数 / 版本**。
- **托盘**常驻：左键唤出窗口；菜单为 打开管理界面 / 复制服务地址 / 退出。

界面要同时表达「多家供应商」与「一个网关」，因此分为**三组**：

```
监控
  ├── 总览          /                 流量、错误、成本、供应商健康度
  ├── 请求日志      /logs             实时尾巴 + 多维过滤
  ├── 用量统计      /usage            按天/模型/供应商/客户端密钥
  └── 账号用量      /accounts         按凭据的额度窗口（仅 CC 等有 Quota 的适配器）
网关
  ├── 供应商        /providers        列表 + 详情（含适配器动态配置与状态面板）
  ├── 模型          /models           模型目录与可路由性
  ├── 路由模型      /route-models     跨供应商模型聚合，对外只暴露一个 ID
  ├── 凭据          /credentials      上游密钥/账号池
  └── 客户端密钥    /keys             sk-adp-* 与额度
设置
  ├── 端点          /endpoints        自定义入口（内置三条只读）
  ├── 设备指纹      /fingerprints     仅当存在需要指纹的适配器时显示
  ├── 设置          /settings        服务/协议/日志参数
  └── 关于          /about          版本、数据目录、运行状态
```

### 2.1 自适应导航

- `/accounts` 仅当**至少一个适配器 `Capabilities.AccountUsage=true`** 时显示；
- `/fingerprints` 仅当**至少一个适配器 `Capabilities.Fingerprint=true`** 时显示；
- `/route-models` 是独立的侧栏页（见 §3.6.1）：它发布的是另一种对外模型 ID；
- 侧栏分组可折叠，状态持久化到 `settings`（`ui.collapsedGroups`）。

> 这一条是「通用化」在 UI 上的直接体现：**界面由适配器能力驱动，而不是写死 Command Code。**

## 3. 页面规格

### 3.1 总览 `/`

四块：

1. **KPI 行**（6 个统计块）：今日请求、成功率、输入 token、输出 token、费用、在途请求。
   每块带图标色块 + 同比（昨日同时段）。
2. **24 小时流量柱状图**：请求数柱；错误段用危险色叠加；峰值高亮 + 合计/峰值摘要。
3. **供应商健康度表**：供应商 / 类型 / 凭据（可用/总数）/ 模型（可路由/总数）/
   最近探活 / 状态药丸（正常 / 无可用凭据 / 已停用 / 适配器告警）。
   点击行 → 跳 `/providers?id=`。
4. **服务信息双栏**：监听地址、数据目录、keep-alive、在途上限、存储降级状态、版本。

### 3.2 请求日志 `/logs`

- 过滤条：端点、状态段（2xx/4xx/5xx）、供应商、模型、客户端密钥、时间范围；
- **实时尾巴开关**：打开后订阅 `/admin/api/logs/stream`，新行插入顶部并高亮 2s；
- 表格列：时间 / 端点 / 供应商 / 模型 / 密钥 / 状态 / 流式 / 耗时 / TTFT / tokens / 费用；
- 行详情抽屉：错误类型、finish_reason、客户端断连、请求 id、凭据 id。

> 流式请求的 TTFT 列是关键可观测项，直接对应「哪些供应商首字慢」。

### 3.3 用量统计 `/usage`

- 分组切换：按天 / 按模型 / 按供应商 / 按客户端密钥；
- 时间范围：近 7 天 / 近 30 天（默认）/ 全部；范围同时约束汇总、趋势与明细；
- **Token 汇总六块**：请求（附平均每请求 token）、输入、输出、缓存（附占输入比例）、
  合计（输入 + 输出）、费用；
- **Token 趋势**：按天堆叠柱状图，输入（强调色）在下、输出（警示色）在上；
  7 / 30 天视图补齐无用量日期（基线短柱），全部视图只画最近 60 天；
  趋势下方给合计 / 峰值与首尾日期；缓存 token 另计，不叠加进柱子；
- 明细表：请求 / 输入 / 输出 / 缓存 / **合计**（每行输入 + 输出）/ 费用。
  缓存列是输入的子集，合计只算输入 + 输出，避免把缓存重复计入。

### 3.4 账号用量 `/accounts`

- 仅对 `AccountUsage` 适配器显示；**按供应商分组**，组内每凭据一张卡片；
- 卡片内容：额度条（按剩余比例变色）、重置倒计时、信用三池（月度/购买/赠送）、
  期账迷你指标（请求数、成功率、费用、token）；
- 操作：单卡刷新、全部刷新、切换承接（pin）；
- 无数据：展示「尚未刷新」与刷新按钮，不展示 0 值误导。

### 3.5 供应商 `/providers`

**列表**：名称 / **类型** / **协议** / 凭据数 / 模型数 / 可路由；点一行在下方展开详情。
类型是接入方式徽标：`反代`（强调色）/ `API`（中性色），由适配器派生
（`accessMode`：`command_code` → 反代，其余 → API），不入库、不可编辑。

**新建 / 编辑弹窗**（`ui.Modal`，Esc 或点遮罩关闭）。新建先选**类型**，再在类型内选择。
布局：名称与类型同行（编辑时无类型，名称独占一排；类型列宽 150，不小于
下拉控件的 140 最小宽度，避免溢出弹窗）；**协议/适配器、BaseURL、
网络代理、上游密钥、自定义 Header 各独占一排**，长字段有完整的输入宽度；
底部操作按钮整行居右，取消在左、保存在右：

| 字段 | 说明 |
| :--- | :--- |
| 名称 | 唯一；默认对外名的来源 |
| 类型 | `API` / `反代`（新建必选，默认 API；编辑时由 kind 派生不可改） |
| 协议 / 适配器 | API 下按协议选：`Anthropic Messages` / `OpenAI Chat` / `OpenAI Responses`；反代下从注册表选适配器（当前只有 `Command Code`） |
| BaseURL | 上游根地址 |
| 上游密钥 | 新建必填；编辑时显示当前掩码，留空或回填掩码表示不修改 |
| 网络代理 | http / https / socks5，可带 `user:pass@`；留空直连 |
| 自定义 Header | 多行 `Key: Value`，随每次上游请求发送 |
| 启用 | 新建默认开 |

API 类的协议与适配器映射由网关决定，界面不暴露 kind：

| 协议 | 适配器 | 记录方式 |
| :--- | :--- | :--- |
| Anthropic Messages | `anthropic` | 由 kind 决定 |
| OpenAI Chat | `openai_compatible` | `adapter_config.protocol = openai_chat` |
| OpenAI Responses | `openai_compatible` | `adapter_config.protocol = openai_responses` |

反代类没有三协议概念：直接选适配器（kind 即选择结果），协议列显示适配器标签；
`adapter_config` 留空走适配器默认值。

编辑时协议的可改范围：OpenAI 两种协议之间可以互切（同一适配器）；
跨适配器的切换不允许，因为它会让已建模型的协议失去意义。

保存语义：新建 = 建供应商 + 首枚凭据；编辑 = 改字段，密钥有值时才写凭据。

**详情**：类型行、适配器能力徽标、基础地址、协议版本，以及 编辑 / 探活 / 启用停用 / 删除。

### 3.6 模型 `/models`

**卡片网格展示**（三次修订：表格 → 卡片）。`ui.Grid` 三列等宽，每张卡片：

- 标题为对外名（默认 `{供应商名}/{上游名}`，即客户端请求里的模型 ID），副标题为上游名；
  标题行右侧「复制」按钮把对外名写入系统剪贴板（`ui.Context.WriteClipboard`），
  flash 提示「已复制到剪贴板」；
- 供应商 · 上游协议一行；能力徽标（流式 / 工具 / 视觉）；
- 价格（输入/输出，每百万 token）与上下文 / 最大输出一行；
- 底部：可路由药丸（不可路由时附原因）+ 启停药丸 + 「更多」下拉（编辑/启用/停用/删除），
  与表格页同一交互模型（菜单是窗口覆盖层，不撑卡片）；删除被路由模型引用时
  服务端返回 409，界面以红色 flash 呈现原因。

编辑弹窗与添加弹窗共用同一个表单：供应商在上游协议只读，可改上游名、显示名、
上下文 / 最大输出、输入 / 缓存 / 输出价格（每百万 token），以及「支持识图」
「支持工具调用」「启用」开关；对外模型 ID 保持创建时的值，不随上游名改名。

过滤：关键字（对外名 / 上游名）。顶部操作：**添加模型** + **从上游拉取**。

**添加弹窗**（`ui.Modal`，Esc / 点遮罩关闭）：

1. 供应商下拉（全部供应商，默认选中第一个）；
2. 上游模型名与显示名（显示名留空取上游名）；
3. 另起一行展示将对外提供的模型 ID：`{供应商名}/{上游名}`，右侧「复制 ID」
   按钮写入系统剪贴板（上游名为空时禁用），与卡片标题的「复制」同一语义；
4. 「保存」→ `admin.Service.CreateModel`：`publicName` 留空由服务端按契约生成
   `{供应商名}/{上游名}`，上游协议取该供应商当前协议（无协议时回退
   `vendor_native`）；成功后关闭弹窗、flash 提示并刷新卡片网格。

**发现弹窗**（`ui.Modal`，Esc / 点遮罩关闭）：

1. 供应商下拉：只列适配器 `Capabilities.ModelDiscovery=true` 的供应商；
2. 「拉取模型列表」→ `admin.Service.DiscoverModels`（OpenAI 兼容适配器即
   `GET {baseURL}/v1/models`），后台执行、弹窗内显示进度与错误；
3. 结果列表：每行一个复选框 + 上游名，行尾灰字预览导入后的对外名
   （`{供应商名}/{上游名}`）；已存在的模型标记「已导入」且不可再选；
   支持全选（只影响未导入项）；
4. 「导入所选」→ `admin.Service.ImportModels`：上游协议取该供应商当前协议
   （表单之外的适配器回退 `vendor_native`），公开名留空按契约生成
   `{供应商名}/{上游名}`；
   完成后显示 新建 / 跳过 / 失败 计数并刷新卡片网格。

### 3.6.1 路由模型 `/route-models`

侧栏「网关」组新增独立页（不再折叠在模型页里），因为它是对外发布的另一种模型 ID：

- **卡片网格**（两列）：标题为路由模型 ID `name`，右侧「复制」与「更多」下拉；
  副标题是 `优先级（主备） · N 个成员`，有备注则再加一行；
  成员逐行列出 `供应商 · 对外模型 ID · P{优先级}`，成员停用时附「成员停用」药丸；
  底部是可路由 / 启停药丸；路由启用但成员全不可路由时给出原因提示；
- **更多**：编辑 / 启用停用 / 删除；删除后成员关系随级联消失；
- **新建 / 编辑弹窗**（`ui.Modal`）：路由模型 ID、备注、启停开关、策略（只读：
  新建为「优先级（主备）」，编辑沿用已存策略）、成员清单；
- **成员清单**：列出**所有供应商的所有模型**（不分组、可滚动），每行复选框 +
  供应商名，勾选后出现优先级输入框（数字越大越先尝试）；提供「全选 / 清空」，
  标题旁显示「已选 N」；至少选一个成员才能保存；
- 保存走 `admin.Service.CreateRouteModel` / `UpdateRouteModel`（成员整体替换）；
  编辑时保留成员的 `enabled` 与 `weight`，桌面端不提供单成员停用；
- 路由模型 ID **不能与已有模型的 `publicName` 相同**，服务端以 409 拒绝，
  弹窗内用红色错误条展示；数据面 `/v1/models` 会把可路由的路由模型一并列出，
  客户端只需拿这一个 ID。

> 契约见 [05 §2.6 / §3.4](05-api-contract.md)。

### 3.7 凭据 `/credentials`

- 按供应商分组的表格：名称 / 密钥（掩码）/ 状态 / 优先级 / 最近使用 / 绑定客户端密钥数 / 操作；
- 状态药丸：`active`（绿）/ `disabled`（灰）/ `exhausted`（橙，附「重置」按钮）；
- 批量导入：多行文本域，`名称,密钥` 或仅密钥；实时统计「将导入 N 枚，重复 M 枚」；
- 一键导入 CLI（CC）：检测 `~/.commandcode/auth.json`，显示掩码预览后导入；
- 固定路由：行内「固定」开关（全局只有一个，互斥）。

### 3.8 客户端密钥 `/keys`

- 表格：名称 / 前缀 / 启用 / 允许模型数 / 允许 IP / 额度（已用/上限）/ 过期 / 最近使用；
- 创建后弹出**一次性明文提示条**（可复制，关闭后不可再取）；
  提示条右侧放「复制」按钮，点击经 `ui.Context.WriteClipboard` 写入系统剪贴板，
  并用 flash 提示「已复制到剪贴板」；轮换产生的新明文走同一提示条；
- 轮换：二次确认 → 返回新明文；
- 额度进度条（`quotaTokens>0` 时显示）。

### 3.9 端点 `/endpoints`

- 内置三条置顶只读行（灰底，`builtin` 徽标，不可编辑/删除）；
- 自定义端点表格 + 编辑抽屉：路径、入站协议、目标（模型/路由模型选择器）、
  是否要求鉴权、限流、超时、启停。

### 3.10 设备指纹 `/fingerprints`

- 顶部「设备档案」：平台/架构/系统版本/伪项目目录/slug/指纹盐是否自定义；
- 每个凭据一张身份卡：thumbmark、machineIdHash、网卡哈希数、osUserHash、hostnameHash、
  gitEmailHash、CPU/核心/内存/时区、下次上报时间、上报结果药丸（指纹 / 生命周期）；
- 说明文字：**同一凭据永远得到同一台设备**，重启不变（决定论派生）。

### 3.11 设置 `/settings`

分组面板，每项带说明副标题：

| 分组 | 项 |
| :--- | :--- |
| 服务 | 监听地址、端口（改动需重启）、keep-alive、在途上限 |
| 协议 | 请求体上限、流式/非流式空闲超时、默认模型、允许匿名 |
| 日志 | 日志文件、级别、保留天数 |
| 上游 | 模型目录刷新间隔、账号用量刷新间隔、漂移检测间隔 |
| 环境 | 被 ENV 钉住的键（只读展示，来自 `envPinned`） |
| 数据 | 数据目录（只读）、密钥文件状态、导出/导入配置 |

### 3.12 关于 `/about`

版本、构建 commit、数据目录、存储降级状态、运行中的适配器清单（含 capability 徽标）、
开源许可与派生声明。

## 4. 组件与设计语言

基础组件 + 两个本项目新增组件：

| 组件 | 用途 |
| :--- | :--- |
| `panel(title, children)` | 卡片容器（Surface + 1px Border + 极淡阴影，12 DIP 圆角） |
| `pill(text, color)` | 状态药丸 |
| `statBlock(icon, label, value, sub)` | KPI 统计块 |
| `emptyState(text, action)` | 空状态 |
| `errorLine()` | 顶部错误条 |
| **`wizard(steps)`**（新） | 三步向导（供应商新建） |
| **`dynamicForm(schema)`**（新） | 由 `ConfigField[]` 渲染表单（适配器配置） |

- 间距刻度 4 DIP；标题 13/11，正文 12/11；
- 颜色统一走主题 `Success/Warning/Danger/TextMuted`；图标 24×24 描边 SVG；
- 表格统一 `ui.Table` + 固定列宽（避免数字变化时抖动）；
- 所有异步动作必须有 `loading` 与 `error` 两条路径，失败不吞错。

## 5. 状态与刷新

- `uiState` 持有每个页面的数据与选择态（`logs/logList/logSelected`…）；
- 页面切换时**按需加载**（首次进入拉数据，之后用缓存 + 手动刷新按钮）；
- 全局「刷新」按钮在页头右上，刷新当前页；
- 总览与账号用量有后台轮询（`reloadQuiet`，不显示 loading，避免闪烁）；
- 写操作成功后局部重取（不整页刷新）。

### 5.1 表格操作列与详情面板（二次修订）

**操作收进每行的下拉菜单。** 三个表格管理页（供应商 / 凭据 / 客户端密钥）
的表格最后一列是固定的「操作」列，每行一个紧凑的 `ui.PopoverMenuButton`
（标签「更多」，11px 字号 + 小内边距，不超过文本行高）。菜单由 mygo 画成
窗口覆盖层，不占行内布局，因此不会撑高或裁剪行。模型页是卡片网格（§3.6），
每张卡片底部放同样的「更多」下拉。

```
筛选/工具栏
表格（只读列 + 操作列[更多 ▾]）
说明: 「选中一行查看详情」
详情面板（选中后出现）: 状态徽标 + 信息行（只读）
```

- 供应商：编辑 / 探活 / 启用停用 / 删除；
- 模型：启用停用；
- 凭据：固定到路由首选项 / 重置为可用 / 停用 / 删除；
- 客户端密钥：轮换 / 删除。

详情面板不再放操作按钮（避免与行内菜单重复），只展示状态与解释文字。

**选中行的对比度。** `ui.Table` 选中行整行填充主题 `Accent`（饱和蓝），
单元格文字若仍用 `Text`/`TextMuted` 会看不清。因此单元格回调一律用
`rowColors(c, selected)` 取色：选中行主/次文字都转为 `AccentText`（白），
状态徽标用 `pillTone` 转为白字 + 半透明白底。日志页的状态色同理。

### 5.2 标题栏避让（实现后修订）

窗口使用 `TitleBarHiddenInset`，系统窗口按钮浮在自绘图层的右上角。
标题栏必须按 `c.TitleBar()` 的 `Left/Right` 内边距布内容，否则「刷新」之类的控件
会画到关闭按钮下面（实测截图里刷新按钮与 ✕ 重叠）。

现在：标题栏只放品牌与运行状态；「刷新」移到页头右侧；
右侧预留 `bar.Right + spM`。

### 5.3 表单描述：图标 + tooltip（五次修订）

字段的备注/描述不再占一行灰字：标签右侧放一个 11px 的 info SVG 图标
（`ui.Icon`，随文字色渲染为 `TextMuted`），描述文字经 `Element.Tooltip`
在悬停或键盘聚焦时显示。`fieldWith` 统一实现，设置页与供应商表单都遵守；
弹窗级别的说明（如「先选类型再选协议或适配器…」）收进标题旁的同款图标。
图标带 `Label("<字段名>说明")`，读屏与测试都能定位。

## 6. 导航与快捷键

| 快捷键 | 动作 |
| :--- | :--- |
| `Ctrl/Cmd + K` | 命令面板（跳页面、新建供应商/模型/密钥、刷新） |
| `Ctrl/Cmd + R` | 刷新当前页 |
| `Ctrl/Cmd + 1..9` | 跳转到第 N 个导航项 |
| `Esc` | 关闭抽屉/向导 |

命令面板（`palette.go`）是导航之外的统一入口：跳页面、新建供应商/模型/密钥、刷新。

## 7. 空状态与首次使用

首次启动（无供应商）时，总览页展示**引导卡**：

```
还没有供应商。三步接入：
 1. 新建供应商（选类型 → 填地址 → 加凭据）
 2. 拉取或新建模型
 3. 创建客户端密钥，把 Base URL 指向 http://127.0.0.1:3050
[ 新建供应商 ]  [ 查看接入指引 ]
```

每个列表页的空状态都必须给出**下一步动作**，而不是只显示「暂无数据」。

## 8. 未来：如果要做 Web UI

## 9. 验收

1. 供应商向导由 `/admin/api/adapters` 驱动：后端加一个假适配器，界面自动出现新卡片与动态表单；
2. 无可用凭据的供应商，在总览健康度表与模型可路由列**同时**可见原因；
3. 日志实时尾巴可开可关，断开后自动重连（3 次退避）；
4. 账号用量页在无 `AccountUsage` 适配器时**整个导航项消失**；
5. 所有写操作失败都有错误条，且不清空用户已填内容；
6. `ui.NewTester` 覆盖：导航切换、空状态、错误条、表格行渲染、向导步骤前进/后退。
